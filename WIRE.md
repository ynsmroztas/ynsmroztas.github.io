# Wire ingest

Polished field notes are still written in this chat. GitHub cannot invent the mitsec voice on every new repo.

## What *is* automatic

1. Tag a public repo with `mitsec-wire`.
2. Weekly Action on this Pages repo lists those repos and opens an issue titled `wire: <repo>` if no matching `*.html` exists.
3. You (or this chat) turn the issue into a note.

## What is not automatic

- Dumping README / PoC scripts onto the site.
- Scanning every new repo you create. GitHub has no user-level “on create repo” hook that writes into Pages unless you add a workflow in that new repo.

## Fast path after a CVE repo

In this chat: repo URL + “siteye ekle”. That is still the quality path.
