The instrument

One app, mapped end to end.

AndroScope is not a background spy APK. It is an operator console plus a target-side runtime. You open the target, you walk the flows, the session writes evidence.

01 · PREPARE

Surface before you touch the UI

Manifest, exported components, deeplink schemas, DEX strings, signing block, framework fingerprints. Findings get FH-IDs so a report can cite them.

02 · ASSESS

Radar, not a dump

Exported activities, backup flags, WebView bridges, weak SDK floors. Risk is calibrated — one exported editor is not a critical RCE.

03 · RUNTIME

You drive. The target is instrumented.

Gadget lives inside the authorized lab build. AndroScope does not sit behind another Play-signed app and watch it. Android process isolation forbids that.

Modules

38+ purpose-built surfaces.

Defense

Pinning, RASP, Play Integrity, biometric and Cronet paths — observed, not promised as a universal kill-switch.

Traffic & secrets

Request and WebSocket intercept, token and crypto dump, gRPC/protobuf, keystore and prefs.

IPC & deeplinks

Intent hunter (capture · replay · inject), schema fuzzer, provider probe, confused-deputy checks.

Native & niche

.so tracer, memory sweep, Lottie / PDF.js / Cordova / RN bridge surfaces when the binary actually has them.
